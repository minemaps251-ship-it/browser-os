# Demo samples

These text files contain no personal data. They are examples to copy into the
BrowserOS VFS through Notes/Editor; they are not imported automatically or bundled
into a user's saved workspace.

- `welcome.txt`: a short document for Notes → Terminal → reload.
- `example.ts`: TypeScript highlighting, search and independent editor history.

The capture script reads these files and saves them through normal UI actions in
an isolated browser context. BrowserOS does not execute `example.ts` or provide
an import feature.
